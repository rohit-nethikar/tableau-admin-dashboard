📊 Tableau Dashboard - Daily & Weekly Checklist

🔵 Daily Check (2 minutes)

⏱️ Time Required: 2 minutes
⏱️ Frequency: Every weekday morning (8-9 AM)
⏱️ Status: Mostly automated, just review results

Automated Daily Check

Your dashboard auto-restarts if it crashes. Just review these quick checks each morning:

✓ If All Green

✓ Status: Healthy
No action needed. Continue to next day.

✗ If Anything is Red

✗ Status: Issue Detected
Action: Run restart command (see Weekly Check section)
If still fails: Review the Troubleshooting section

⏱️ Time Required: 5 minutes
⏱️ Frequency: Every Monday at 9:00 AM (Automatic)
⏱️ Action: Review automated report

Weekly Report Review

Automated health check runs every Monday at 9 AM. Review the results:

View the Health Report

What to Look For

✓ Healthy Report Shows

  • ✓ Task Status: RUNNING
  • ✓ Port 5000: LISTENING
  • ✓ Dashboard: OK (HTTP 200)
  • ✓ No recent errors

✗ Unhealthy Report Shows

  • ✗ Task Status: STOPPED
  • ✗ Port 5000: NOT LISTENING
  • ✗ Dashboard: Failed
  • ✗ Recent errors found

If All Checks Pass

✓ Status: Healthy
Log this result and continue with normal operations.

If Any Check Fails

✗ Status: Requires Action
1. Restart the service:
Restart-ScheduledTask -TaskName "TableauAdminDashboard"

2. Wait 30 seconds, then test:

Start-Process "http://localhost:5000"

3. If still failing, check logs:

Get-Content "C:\Users\m239012\AppData\Local\nssm\TableauAdminDash\stderr.log" -Tail 50

⚠️ Common Issues & Quick Fixes

❌ "Connection Refused" Error

Cause: Service has stopped

Fix:

Restart-ScheduledTask -TaskName "TableauAdminDashboard"

❌ Page Shows "Internal Server Error"

Cause: Configuration or database issue

Fix:

Stop-ScheduledTask -TaskName "TableauAdminDashboard" Start-Sleep -Seconds 5 Start-ScheduledTask -TaskName "TableauAdminDashboard"

❌ Task Shows "STOPPED"

Cause: Service crashed and didn't auto-restart

Fix:

Start-ScheduledTask -TaskName "TableauAdminDashboard"
