🎯 Your Weekly Checklist (Takes 2 Minutes)

Every Monday Morning - Just Do This:

  1. Open health check report:
    notepad "C:\Users\m239012\OneDrive - Mayo Clinic\GitHub_claude\tableau-admin-dashboard\health-check-log.txt"
  2. Check if all items show ✓ (green):
    • ✓ Task Status: RUNNING
    • ✓ Port 5000: LISTENING
    • ✓ Dashboard: OK (HTTP 200)
    • ✓ No recent errors
  3. If all green: Done! Status is healthy. Continue to next Monday.
  4. If anything red: Run quick restart command:
    Restart-ScheduledTask -TaskName "TableauAdminDashboard"

🚀 What Happens Automatically Behind the Scenes

1
Windows Boots
Task Scheduler sees that TableauAdminDashboard task should be running at startup → Launches start-app.ps1
2
Virtual Environment Activates
start-app.ps1 activates .venv and loads all Python dependencies
3
Application Starts
Python runs app.py, Flask starts listening on port 5000
4
Continuous Monitoring
start-app.ps1 infinite loop continuously checks if process is running
5
If Crash Detected
Infinite loop catches the exit, waits 10 seconds, restarts automatically
6
Weekly Health Check
Every Monday 9 AM, health-check.ps1 runs and generates detailed report
7
Logging & Alerts
All activity and errors logged to stdout.log and stderr.log automatically

🔍 How to Verify Everything is Running

Method 1: Check Task Status (PowerShell)

Get-ScheduledTask -TaskName "TableauAdminDashboard" | Select-Object State

Expected: State = Running

Method 2: Check Port is Listening

netstat -ano | findstr :5000

Expected: Shows active connections on port 5000

Method 3: Access in Browser

Open: http://localhost:5000

Expected: Dashboard loads successfully
