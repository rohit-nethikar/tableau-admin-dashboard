🆘 Troubleshooting Quick Checklist

  • Is the task scheduled and running? → Check Task Scheduler
  • Can you access http://localhost:5000? → Check browser
  • Is port 5000 listening? → netstat -ano | findstr :5000
  • Are there error logs? → Check stderr.log (above)
  • Windows Firewall blocking? → Allow Python.exe for Private networks
  • Need to restart? → Restart-ScheduledTask -TaskName "TableauAdminDashboard"
