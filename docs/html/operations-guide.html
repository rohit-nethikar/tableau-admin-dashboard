✅ How to Check If It's Running

Method 1: Check Task Scheduler (Recommended)

Get-ScheduledTask -TaskName "TableauAdminDashboard" | Select-Object TaskName, State

Expected output:

TaskName State -------- ----- TableauAdminDashboard Running

Method 2: Check if Port 5000 is Listening

netstat -ano | findstr :5000

Expected output: (Shows connections on port 5000)

TCP 127.0.0.1:5000 127.0.0.1:xxxxx ESTABLISHED

Method 3: Test in Browser

Open: http://localhost:5000

  • If it loads: ✅ Running
  • If "Connection refused": ❌ Not running

⚠️ Troubleshooting

Issue: Dashboard won't start

Step 1: Check the task status

Get-ScheduledTask -TaskName "TableauAdminDashboard" | Select-Object State

Step 2: Check the logs

Get-Content "$env:APPDATA\Local\nssm\TableauAdminDash\stderr.log" -Tail 100

Step 3: Try running manually

cd "C:\Users\m239012\OneDrive - Mayo Clinic\GitHub_claude\tableau-admin-dashboard" .\.venv\Scripts\python.exe app.py

Step 4: Check Python environment

.\.venv\Scripts\python --version .\.venv\Scripts\pip list | grep -i flask

Issue: "Connection refused" when accessing http://localhost:5000

Check 1: Is the task running?

Get-ScheduledTask -TaskName "TableauAdminDashboard" | Select-Object State # Should show: Running

Check 2: Is port 5000 open?

netstat -ano | findstr :5000 # Should show active connections

Check 3: Check Windows Firewall

  • Windows Defender Firewall → Allow an app through firewall
  • Verify Python.exe is allowed for Private networks

Check 4: Try from another computer

http://YOUR-MACHINE-NAME:5000

Issue: Dashboard shows "Internal Server Error"

Solution:

# 1. Stop the task Stop-ScheduledTask -TaskName "TableauAdminDashboard" # 2. Wait 5 seconds Start-Sleep -Seconds 5 # 3. Start the task Start-ScheduledTask -TaskName "TableauAdminDashboard"

📅 Daily Health Check

Run this daily to verify everything is working:

# Check 1: Task is running Get-ScheduledTask -TaskName "TableauAdminDashboard" | Select-Object State # Check 2: Port 5000 is listening netstat -ano | findstr :5000 # Check 3: Dashboard responds $response = Invoke-WebRequest -Uri "http://localhost:5000" -UseBasicParsing -ErrorAction SilentlyContinue if ($response.StatusCode -eq 200) { Write-Host "✓ Dashboard is responding" -ForegroundColor Green } else { Write-Host "✗ Dashboard is not responding" -ForegroundColor Red }
✅ If all three checks pass: Everything is healthy. Continue to next day.
❌ If any check fails: Run restart command and review logs.
