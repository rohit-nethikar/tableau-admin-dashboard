🔌 Connected Apps

A Connected App is a Tableau Server OAuth/JWT direct-trust relationship, used to let an embedded dashboard or an external application call the REST API on a user's behalf without a login prompt. "Project Scope" shows which projects the app is restricted to embedding content from — "All Projects" means Tableau applied no restriction. This list requires the PAT this app uses to belong to a server or site admin, and Tableau Server 2022.3+ (REST API 3.17+); tableauserverclient has no native wrapper for this endpoint, so this page is built from a raw REST call (same approach as Custom Views' usage-statistics lookup). On an older server or a non-admin PAT, this section will show a sync error on Refresh Health instead of populating — that's expected, not a bug.
