📊 Workbooks

"Stale" flags workbooks whose content hasn't been updated in {{ stale_threshold_days }}+ days, based on last-updated (content modified) date. "Views" is a lifetime total from the REST API (not a recent-activity window) — see README.md. "Revisions" is capped by the server's configured revision-retention setting, not true unlimited history. "Extract Failures" counts extract-refresh job failures back from the most recent job and is bounded by however much job history Tableau Server currently retains — this is Tableau's own extract job history, not this app's sync runs (see Refresh Health's "Consecutive Sync Failures" for that). "Connection Type" reflects the underlying connection driver(s) — "Mixed" means the workbook has both a live connection and an extract. "Data Source(s)" comes from the Metadata API (same as the Lineage page) and will be blank while that API is unreachable. "Extract Run Duration" is how long the most recent extract-refresh job took (completed minus started); it's blank if that job never completed or Tableau didn't report a start time. "Next Scheduled Refresh" is blank if the resource has no server-managed extract-refresh schedule (e.g. it's all-live-connection, or only ever refreshed on demand) — a blank cell does not mean refresh is broken. "Owner Last Login" is blank for a user who has never logged in. A workbook with no Project is in the owner's Personal Space — Tableau's private per-user area for content not yet published to a project. Permissions can't be set on Personal Space content (it's private to the owner and site/server admins by design), so it never appears on the Permissions page.
