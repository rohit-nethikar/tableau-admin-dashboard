Published Data Sources

"Stale" flags data sources whose content hasn't been updated in {{ stale_threshold_days }}+ days. "Connection Type" reflects the underlying connection driver(s) on this data source — "Mixed" means it has both a live connection and an extract. "Underlying Source(s)" lists what each connection actually points at — a database/file driver and server, or, when this data source is built on top of another published data source, that data source's name — i.e. per-connection detail beneath the coarser "Connection Type" summary. "Type" is the connector/database type Tableau reports for the data source itself (e.g. postgres, excel). "Lifetime Views" comes from the Metadata API and is a lifetime total, not a recent-activity count — it shows blank if the Metadata API isn't reachable (unlike workbook views, there's no REST fallback for data source usage). "Revisions" is capped by the server's configured revision-retention setting, not true unlimited history. "Extract Failures" counts extract-refresh job failures back from the most recent job and is bounded by however much job history Tableau Server currently retains — this is Tableau's own extract job history, not this app's sync runs (see Refresh Health's "Consecutive Sync Failures" for that). "Extract Run Duration" is how long the most recent extract-refresh job took (completed minus started); it's blank if that job never completed or Tableau didn't report a start time. "Next Scheduled Refresh" is blank if the resource has no server-managed extract-refresh schedule (e.g. it's all-live-connection, or only ever refreshed on demand) — a blank cell does not mean refresh is broken. "Owner Last Login" is blank for a user who has never logged in. See README.md.
