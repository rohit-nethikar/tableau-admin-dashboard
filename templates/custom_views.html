👀 Custom Views

Tableau's saved-view-per-user feature. "Shared" means the view is visible to anyone with access to the workbook, not just its owner. A non-admin PAT may only see custom views it owns or that are marked shared — a Tableau Server-side restriction. "View" is the base worksheet/dashboard the custom view saves a filter/selection state on top of. Tableau's REST and Metadata APIs do not expose the actual filter values, parameter settings, or mark selections saved inside a custom view — that state lives only in the workbook's internal view definition, so it can't be listed here; "Project" and a direct link to the parent workbook are shown instead to help you find and inspect it in Tableau. "Last Accessed" is blank if the view has never been opened by anyone since it was created.
