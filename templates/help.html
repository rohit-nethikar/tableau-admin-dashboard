📚 Tableau Admin Dashboard Guide

What is This Dashboard?

The Tableau Admin Dashboard is a centralized management and monitoring tool for Tableau Server administrators. It provides visibility into your Tableau environment's health, usage, content, permissions, and performance metrics.

📖 Pages Overview

Dashboard

Overview: High-level summary of your Tableau environment with key metrics, findings, and health scores.

Users

Manage Users: View all users on the site. Filter by Active/Inactive status. Monitor user engagement and identify inactive users.

  • ✅ Active Users: Logged in within {{ stale_threshold_days }} days
  • 🔴 Inactive Users: Haven't logged in for {{ stale_threshold_days }}+ days

Workbooks

Content Management: Browse all workbooks. See ownership, project, refresh status, and usage metrics.

Data Sources

Data Governance: Monitor data sources, certifications, refresh status, and extract health.

Custom Views

User-Created Content: Track custom views created by users. Filter by workbook, owner, account type. View account numbers.

📊 Analysis & Monitoring

Analytics

Usage Insights: View most viewed workbooks, sheets, and custom view distribution. Filter by date range (7d, 30d, 90d, all).

License Usage

Licensing: Monitor Creator, Explorer, and Viewer seat usage vs. capacity. Track trends over time.

Findings

Issues & Insights: System-identified issues across permissions, content, and configuration. Track and resolve findings.

Permissions

Access Control: View all permission grants on projects and workbooks. Identify risky configurations.

Health

Content Health: Scoring based on usage, ownership, refresh, certification, documentation, and lineage.

Background Jobs

Job Queue: Monitor extract refreshes, subscriptions, and flow runs. Cancel pending jobs if needed.

⚙️ Key Features

🔍 Filtering & Search

Most pages support filtering to narrow down results. Use filters to find specific workbooks, users, or content.

📊 Visualizations

Charts show trends, distributions, and comparisons. Hover over data points for details.

⏱️ Date Ranges

Analytics page supports date filtering (7 days, 30 days, 90 days, all-time) to see recent trends.

🔄 Real-Time Data

Dashboard syncs data from Tableau Server periodically. Click "Sync Now" for immediate refresh.

🎯 Multi-Site Support

Select site from top-right dropdown to switch between Tableau Server sites.

📥 Export Data

Some pages support CSV export. Look for "Export" buttons to download filtered data.

✅ Common Tasks

How to find inactive users?

Go to Users page → Select filter "🔴 Inactive Users" → See all users who haven't logged in for {{ stale_threshold_days }}+ days.

How to check license usage?

Go to License Usage page → See current Creator, Explorer, Viewer seat usage and trends over time.

How to monitor extract refreshes?

Go to Background Jobs page → See active/recent jobs and their status. Cancel pending jobs if needed.

How to find unused workbooks?

Go to Workbooks page → Look for low usage metrics and/or stale content (⏱️ indicator).

How to track custom views?

Go to Custom Views page → See all saved views with owner, account number, and account type (Mayo/Non-Mayo).

How to see permission issues?

Go to Findings page → Filter for "permission_risk" category to see access control issues.

💡 Tips & Best Practices

  • 📌 Bookmark frequently used pages: Overview, Users, Findings, License Usage
  • 🔄 Sync regularly: Click "🔄 Sync Now" to get fresh data from Tableau Server
  • 🎯 Use filters: Filters help narrow down large datasets (workbooks, users, findings)
  • 📊 Monitor trends: Check Analytics and License Usage for trends over time
  • 🔴 Act on Findings: Review and resolve "Findings" regularly to maintain a healthy Tableau environment
  • 👥 Manage inactive users: Review and disable/remove inactive users to optimize licensing
  • 📦 Track custom views: Monitor custom view creation to understand user-created content
  • 🛡️ Review permissions: Regularly audit permissions to ensure proper access control
