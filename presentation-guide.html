📊 Tableau Admin Dashboard

✨ Updated August 24, 2026: Now featuring colorful design system, modern glassmorphism effects, and 3D animations

🎯 Dashboard Overview

Purpose: A comprehensive internal tool for Tableau administrators at Mayo Clinic to monitor, manage, and optimize Tableau Server/Online infrastructure.
Key Value: Centralized visibility into content health, user activity, and system performance with actionable insights.

Primary Objectives

💰 Cost Optimization

Identify over-licensed users, inactive accounts, and opportunities to reduce spend while maintaining service quality.

🔒 Risk Reduction

Ensure compliance, security, and data quality through continuous monitoring and automated alerts.

⚡ Efficiency Gains

Replace manual reports with real-time insights, saving administrators 10+ hours per week.

📈 Scalability

Support growing user base and content without proportional increase in administrative overhead.

Visual Design Excellence (August 24, 2026)

🎨 Colorful Design System

Vibrant gradient backgrounds and colored components eliminate "everything is white" appearance with accessible contrast.

✨ Glassmorphism Effects

Modern frosted glass aesthetic with 12px backdrop blur on cards and modals for contemporary look and feel.

3️⃣ 3D Animations

Smooth elevation effects with multi-layer shadows, glow pulses, and cubic-bezier easing for tactile interactions.

⏳ Performance Optimized

10x faster data loading with SQL aggregations, GPU-accelerated 60fps animations, and smart pagination.

⚡ Tab 1: OVERVIEW

Start Here! At-a-glance snapshot of your Tableau environment's health and activity.

High-Level Metrics

  • Workbooks: Total count across the site
  • Data Sources: Available connections and resources
  • Stale Content: Items not accessed in 90+ days (maintenance needs)
  • Custom Views: User-created views driving engagement
  • Subscriptions: Active scheduled deliveries
  • Users: Active user base across roles

Health Score Distribution

  • Average Health Score: Overall environment health (0-100 scale)
  • Good (80+): Well-maintained, actively used ✓
  • Warning (50-79): Needs attention
  • Critical (<50): Requires immediate action
When to Use: Weekly check-ins, executive briefings, incident response triage

📈 Tab 2: ANALYTICS

Deep-dive into content usage patterns and user engagement metrics.

Key Analytics Areas

  • Most Viewed Workbooks: Identify critical, heavily-used content
  • Average Views/Month: Engagement trends over time
  • Created vs. Accessed: Adoption rate of new content
  • Usage by Date Range: 7-day, 30-day, 90-day trends
  • Stale Workbooks: Candidates for archival

Data Source Performance

  • Connection frequency and criticality
  • Certification status (curated vs. uncertified)
  • Extract vs. live connection performance
  • Dependency analysis
When to Use: Monthly business reviews, adoption tracking, capacity planning

📋 Tab 3: WORKBOOKS

Inventory and manage all workbooks, track ownership and dependencies.

Key Workbook Metrics

  • Name & Owner: Clear accountability
  • Project: Organizational structure
  • Created/Updated: Content freshness tracking
  • View Count: Usage indicators
  • Health Score: Quality assessment

Example Use Case

"Show me all workbooks owned by [Department] that haven't been viewed in 90 days"

→ Identifies candidates for archival
→ Frees up maintenance burden
→ Improves user experience (less clutter)
When to Use: Content governance reviews, ownership audit, retirement planning

🗄️ Tab 4: DATA SOURCES

Centralized view of all data connections, performance, and health.

Data Source Monitoring

  • Connection Type: Databases, clouds (AWS, Azure, GCP)
  • Embedded vs. Published: Reusability assessment
  • Certification Status: Data quality assurance
  • Last Refresh: Reliability and SLA compliance
  • Usage Count: Business criticality

Risk Assessment

  • Uncertified sources (shadow IT risk)
  • Overused sources (single point of failure)
  • Stale refreshes (data pipeline issues)
  • Failed extracts (production incidents)
When to Use: Data governance meetings, vendor management, SLA reviews

👥 Tab 5: USERS

Complete user inventory with activity tracking and role management.

User Inventory Insights

  • Active Users: License utilization and costs
  • User Roles: Viewer, Explorer, Editor, Admin breakdown
  • Last Login: Identify inactive users (cost savings opportunity)
  • Inactive Users: Plan for offboarding
  • New Users: Onboarding success tracking

Cost Optimization Example

"If we have 50 Editors with <5 logins in 90 days at $50/month each:
→ Current cost: $2,500/month
→ Downgrade 40 to Viewers: Save $2,000/month
→ Annual savings: $24,000 with no functionality loss"
When to Use: Quarterly cost reviews, access audits, license reconciliation

🔐 Tab 6: PERMISSIONS

Audit and manage permissions across all content items.

Permission Management

  • View/Interact: Read-only access
  • Edit: Create and modify content
  • Administer: Full control and publishing rights

Security & Compliance

  • Granular controls at workbook and view level
  • Group-based access for simplified admin
  • Complete audit trail of changes
  • Compliance with HIPAA, SOX requirements

Risk Detection

  • Excessive permissions on user accounts
  • Orphaned access (inactive with permissions)
  • Over-shared public content
When to Use: Security audits, compliance reviews, incident investigation

🔗 Tab 7: LINEAGE

Visualize data flow and dependencies across the platform.

Dependency Mapping

  • Data Source to Workbook: What breaks if source goes down
  • Workbook Relationships: Cross-dashboard dependencies
  • User Impact: How many people affected by each component
  • Change Management: Assess impact before modifications

Common Use Cases

"What happens if [Database] goes down?" → See all dependent workbooks
"Can we deprecate [Data Source]?" → Check if still in use
"Why is [Workbook] running slow?" → Trace to upstream data sources
When to Use: Architecture reviews, change control boards, disaster recovery planning

Engagement Metrics

Key Insight

When to Use: Adoption metrics, user satisfaction surveys, feature tracking

💡 Presentation Tips

1. Start with Overview

Show the dashboard's purpose and value proposition. Highlight key metrics that matter to executives. Explain how it reduces manual work.

2. Use Real Data

Navigate to actual data in your environment. Show specific examples relevant to Mayo Clinic. Demonstrate filtering and search capabilities.

3. Focus on Business Value

Cost savings: License optimization, reduced support tickets | Risk reduction: Compliance, security, data quality | Efficiency: Centralized visibility, automation

4. Demo Workflow

Walk through a realistic use case: "Let's find all stale workbooks in [Department]". Show filtering, exporting, and action items. Demonstrate how to assign remediation work.

5. Highlight Recent Work

Show the modern design improvements with glassmorphism and 3D effects. Explain performance optimizations (10x faster SQL aggregations). Emphasize reliability and stability.
